# Wanzy Community - Official Bio Links Website

Website Linktree custom modern dengan tema **Neon Violet / Cyber Purple**, animasi kupu-kupu terbang bersinar di background, dan layout glassmorphism profesional.

## Struktur File
- `index.html` : Struktur utama halaman, bio, avatar, dan daftar link.
- `css/style.css` : Desain tema ungu glowing, glassmorphism, responsive mobile.
- `js/butterfly.js` : Efek animasi kupu-kupu terbang realistis dengan canvas HTML5.

## Cara Pasang & Deploy ke GitHub Pages (100% Gratis)
1. Buat repository baru di [GitHub](https://github.com/new), contoh nama: `wanzy-community`.
2. Upload semua file (`index.html`, folder `css`, folder `js`).
3. Masuk ke tab **Settings** > **Pages** di repository GitHub kamu.
4. Pada menu **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu 1 menit, website kamu langsung live dan bisa diakses dari seluruh dunia!

## Cara Kustomisasi
- **Edit Link & Nama**: Buka `index.html`, kamu bisa ubah teks judul, bio, serta `href=""` ke link WhatsApp, Shopee, Discord, atau IG milikmu.
- **Ganti Foto**: Ubah atribut `src` pada tag `<img class="profile-img">` dengan link foto profilmu.
